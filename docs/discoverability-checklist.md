# Sean Whalen discoverability checklist

The website handles the technical foundation: one canonical GitHub Pages URL, distinct
page titles and descriptions, a crawlable publication index, a sitemap, and structured
data for Sean, the About page, the work index, and _Small ecologies_.

The remaining high-value steps require an account or a choice only Sean can make.

## Do next

1. Add `https://holdenbrown.github.io/sean-whalen-poetry/` as a Google Search Console
   property and submit
   `https://holdenbrown.github.io/sean-whalen-poetry/sitemap.xml`. Search Console does
   not require Analytics or a tracking script. Use URL Inspection for the homepage after
   verification.
2. Apply to the [Poets & Writers Directory](https://www.pw.org/directory). Its
   [listing criteria](https://www.pw.org/directory/criteria) require 12 poetry points;
   Sean's verified journal publication history appears to clear that threshold, but
   Poets & Writers makes the eligibility decision.
3. Consider a free, author-controlled [ORCID iD](https://info.orcid.org/researchers/) to
   connect Sean's name to the Iowa State thesis and DOI. Add it to this site only after
   Sean supplies the authenticated identifier.
4. Put the official site URL in every future contributor biography. Ask willing journals
   with existing Sean Whalen author pages to add the same link.
5. If Sean wants direct inquiries, create a dedicated professional email address and
   explicitly approve it for publication before adding a contact link. Do not publish a
   private or inferred address.

## Editorial maintenance

- Add verified publications through the repository's **Add publication** GitHub Actions
  workflow.
- Prefer a direct poem page, then an issue PDF, then an issue scan, then a bibliographic
  record.
- Do not add poem text, unpublished claims, awards, readings, social profiles, or contact
  details without Sean's approval and a reliable source.
- Keep the supplied portrait credit and watermark. Obtain explicit website reuse
  permission before replacing it with an unwatermarked file or offering it as press
  media.
